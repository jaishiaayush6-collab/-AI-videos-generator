AI CREATOR STUDIO - STARTER WEBSITE

Files:
- index.html (dashboard)
- video-movie.html
- text-to-image.html
- text-to-voice.html
- text-to-story.html
- text-to-song.html
- image-to-video.html
- image-to-story.html
- image-to-song.html
- ai-editor.html
- style.css (shared responsive design)
- app.js (demo form and image preview)

How to use:
1. Extract the ZIP.
2. Open index.html in a browser, or upload all files to a GitHub repository.
3. Keep all HTML files, style.css and app.js in the same folder.

Important:
This is a front-end UI starter. It does not generate actual AI media yet.
For real generation, create a secure backend (for example Node.js/Express or Python/FastAPI)
and connect each form to the appropriate AI provider. Never place private API keys in browser code.
